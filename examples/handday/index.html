16px 占绝对主导。官网实测 1639 次，是第二名的 10 倍以上。

官网实测数据：字号 16px 出现 1639 次，14px 152 次，18.15px 37 次。字重 400 出现 1961 次，700 只有 68 次。

说明这个产品几乎不用中间字重，只有「常规」和「加粗」两种。

间距与圆角

间距 8px 基准，圆角以 8px 为主（出现 225 次）。

  • 间距基准8px。8px 出现 225 次，是 4px（53次）的 4 倍多。实际使用 8/12/16/24 四档。
  • 卡片圆角8px。搜索框、地图卡、分类缩略图统一 8px。
  • 小标签圆角4px。角标、小按钮用它。
  • 促销条圆角15px。全站最大的圆角，只有限时特价条用。
  • 标题栏圆角0 0 8 8。只圆下两角，形成"顶部整块"的视觉。
  • 页面边距12px。左右各 12，比常见的 16 更紧，为了塞更多内容。

设计原则

这些原则解释「为什么它长这样」，和主流 C 端产品的逻辑相反。

  • 实心色块定调标题栏用大面积实心蓝，一眼确认品牌身份。不做渐变、不做毛玻璃。
  • 橙蓝分工蓝色管信任和导航，橙色管行动和促销。两者不会出现在同一层级上。
  • 照片代替图标分类用真实门头照片，不用线性图标。采购员凭照片认部门，比读文字快。这是 B 端特有的做法。
  • 信息密度优先一屏 8-10 个信息块，没有装饰性留白。用户是来进货的，不是来欣赏的。
  • 商业元素前置公告、电话、限时特价、登录引导全在首屏。每一块都在促成交易。
  • 浅蓝底分层页面底 #F2F6FF，卡片纯白，靠色差分层，不用阴影。小程序性能有限，这是务实选择。
  • 选中态用橙不用蓝TabBar 选中是橙色。因为蓝色已被标题栏占用，橙色更适合表示"当前操作"。

代码

WXSS 变量文件，可直接放进小程序项目。

theme.wxss（节选）
page {
  --color-primary: #3461FF;
  --color-accent: #ED7D31;
  --color-bg-page: #F2F6FF;
  --color-text: #111111;

  --space-sm: 16rpx;   /* 8px */
  --space-md: 24rpx;   /* 12px */
  --radius-md: 16rpx;  /* 8px */

  --font-body: 32rpx;  /* 16px */
  --navbar-height: 88rpx;
  --tabbar-height: 100rpx;
}
  • 标题栏高度要按胶囊按钮位置动态算，不能写死 44px。用 wx.getMenuButtonBoundingClientRect()。
  • 底部安全区TabBar 要加 env(safe-area-inset-bottom)，登录浮条要叠在 TabBar 上方。
  • 分类缩略图112rpx × 112rpx（56px），object-fit: cover，圆角 8px。建议上传方形图。
  • 公告滚动可用 <swiper vertical> 做跑马灯，高度固定 32px。
